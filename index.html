Arm windows from your agent

This tracker is a static page — your agent just opens plain links. No server, no cost. Copy the instructions below into your harness and it can wire hooks itself.

Link protocol
#start=claude              arm the window now
#start=claude&in=90m       custom window length
#cap=codex                 mark limit hit
#cap=codex&resets=18:44    reset time copied from the CLI message
#cap=codex&in=38m          or relative
#drain=qwen&used=620k      token pool exhausted → cooldown starts
Wiring (example: session-start hook)
"hooks": { "SessionStart": [{ "hooks": [{
  "type": "command",
  "command": "open '<app-url>#start=zcode&src=zcode'"
}] }] }

macOS: open '<app-url>#start=codex' · Linux: xdg-open · Windows: start. Links are idempotent — they never double-arm an active window.

Sync across devices via gist

All state lives in one JSON file inside a private GitHub gist. Any device that knows the session code can read it — even curl from a terminal. One device keeps a token to push updates. No backend, no cost.
